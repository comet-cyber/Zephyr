.. zephyr:code-sample:: quality-of-service
   :name: 服务质量 (QoS)
   :relevant-api: ethernet

   演示以太网层上的服务质量（QoS）机制。

概述
********

本示例旨在展示以太网（Ethernet）层上的服务质量（Quality of Service，QoS）功能。

构建与运行
********************

按如下方式构建：

.. zephyr-app-commands::
   :zephyr-app: samples/net/qos/ethernet
   :board: <board_to_use>
   :goals: build
   :compact:

本示例仅适用于本地模拟器（native_sim）。示例启动后，它会在虚拟网络接口上模拟传入的网络数据包，并打印相关的统计信息。

使用以下命令运行：

.. zephyr-app-commands::
   :zephyr-app: samples/net/qos/ethernet
   :host-os: unix
   :board: native_sim
   :goals: run
   :compact:
